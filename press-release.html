Galgje v20.1.2 — Game elapsed time on screen and in screenshots

Release date: July 14, 2026
Platform: Windows 10 / 11
Developer: Thijs Boekholt

Summary

Galgje v20.1.2 adds a subtle game elapsed time display on the main window, Live Stats board, Word Progress window, and winner/dashboard screenshots. Elapsed time is cumulative across resumed games.

Highlights

Game elapsed time

  • Bottom-right of main window (above copyright, no overlap)
  • Live Stats board and full-screen Word Progress
  • BING BING winner clipboard text and last-game dashboard (1920×1080)
  • Includes time from resumed games

Word Browser & statistics

  • Played words only filter; clearer online definitions
  • Stats Audit, authoritative manual edits, GitHub release packaging
