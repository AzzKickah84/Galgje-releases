Press Release

Galgje v20.1.3 — Custom data locations, Stats Audit fixes, and offline manual

Release date: July 14, 2026
Platform: Windows 10 / 11
Developer: Thijs Boekholt

Summary

Galgje v20.1.3 adds a Data locations settings tab for pointing game data to a local folder or network share, fixes Stats Audit logging, improves dialog layouts across the app, and ships an updated user manual with screenshots in a shareable offline ZIP.

Highlights

Data locations (Settings)

  • Choose where stats, logs, word history, and backups are stored
  • Support for network shares (e.g. \\server\share\Galgje)
  • Test access, copy/move existing data, optional ZIP backup before migration
  • App settings stay on each PC; restart after changing data folder

Stats Audit

  • Permanent log of every stat change (manual edit, game end, import, reconcile)
  • Filters by player, source, and date range

UI improvements

  • Layout fixes across Player Manager, Settings, Stats Health, Word Browser, and more

Documentation

  • Updated user manual with screenshots
  • Offline manual ZIP for sharing without internet
