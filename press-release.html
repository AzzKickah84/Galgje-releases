Press Release

Galgje v20.1.0 — Hangman game update strengthens statistics and word tools

Release date: July 14, 2026
Platform: Windows 10 / 11
Developer: Thijs Boekholt

Summary

Galgje v20.1.0 delivers easier-to-read word definitions, reliable statistics, and improved GitHub release packaging with manual and press release included.

Highlights

Statistics you can trust

  • Manual stat edits are never silently reverted
  • New Stats Audit tab logs every change with timestamp, player, metric, and source
  • Stats Health Center and Compare Stats now support ignoring known differences

Word Browser

  • Browse 390,000+ Dutch and 370,000+ English dictionary words
  • Look up meanings from Wiktionary, Van Dale, and dictionary APIs
  • Responsive filtering with debounced search fields

Installer improvements

  • Choose to keep, back up, or delete existing game data during setup
  • Shareware license and changelog integrated into the setup wizard
  • Build version timestamps now match the user's local time

Polish

  • Hall of Fame player names are more prominent
  • Custom Galgje icon across application and installer
  • Network compatibility uses sequential release numbers

System requirements

  • Windows 10 or later (64-bit)
  • ~52 MB installer (self-contained, includes .NET runtime)
  • No internet required to play; optional for word meaning lookups

Download

Download latest Galgje installer

Game data is stored in %LocalAppData%\Galgje and is preserved across upgrades unless the user chooses a fresh install.
