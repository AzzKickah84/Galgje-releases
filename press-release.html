Core Gameplay — Classic Rules, Smart Systems

🎯

Letter-by-Letter Guessing

Guess one letter at a time. Correct letters reveal in the word; wrong guesses advance the custom-drawn gallows. Duplicate letters count as wrong — no free retries.

👥

Unlimited Multiplayer

Add as many local players as you want. Each has individual error tracking, elimination status, guess history, and persistent career stats.

📝

Three Ways to Pick a Word

Type a custom word, pull a random word from bundled Dutch (OpenTaal) or English lists (offline), or double-click any previously played word to replay it.

⚖️

Smart Error Limits

Per-player wrong-guess caps scale with roster size (4 for 3+ players, 10 for head-to-head). Eliminate, un-eliminate, or mark a winner manually.

👑

The AzzMastah Rule

When 10 total wrong guesses pile up or the timer hits zero, the host “AzzMastah” wins automatically — a signature twist for competitive nights.

⏱️

Pressure-Cooker Timer

Default 5-minute countdown (+20s correct, −30s wrong). Pause/resume anytime. Green → orange → red urgency colors. Configurable in Settings.

🔊

Audio Feedback

Wrong-guess sound and celebratory “BING BING” victory fanfare. One-click mute from the menu or toolbar with a visual indicator.

💾

Session Persistence

Close the app mid-game and come back — your session, log, notes, and roster survive between restarts.

Data, Privacy & Import

  • All player data lives in %LocalAppData%\Galgje\ — never in Program Files
  • Files: player_statistics.log, hangman_log.txt, played_words.txt, notes.txt, player_achievements.json, word_game_history.json
  • Example data ships in example-data\ for previewing formats before import
  • Full visual import guide in the bundled User Manual
  • Automatic migration from legacy install-folder data on first run
  • Optional anonymized metrics to a self-hosted dashboard via webconfig.ini (disabled by default)
