New Here? How Hangman Works

Never played Hangman before? It takes about a minute to learn. One person (the host) knows a secret word; everyone else tries to figure it out by guessing one letter at a time.

1. There is a hidden word

The word is shown as blanks - one underscore per letter, e.g. _ _ _ _ _ _ _ for a 7-letter word. Nobody but the host can see the answer.

2. Players guess letters

On your turn you guess a single letter. If that letter is in the word, every copy of it is revealed. If it is not, it counts as a wrong guess.

3. Wrong guesses build the gallows

Each wrong guess draws one more part of the hangman figure. Too many wrong guesses and the round is lost (or you are eliminated).

4. Win by completing the word

Reveal every letter before the gallows is finished (and before the timer runs out) and you win the round.

The goal in one sentence

Guess the hidden word, letter by letter, with as few wrong guesses as possible - before the timer hits zero.

What makes Galgje different from pen-and-paper Hangman

  • Many players at once - everyone shares the same word; Galgje tracks each player's guesses and errors separately.
  • A live timer - correct guesses add time, wrong guesses subtract it (you can turn it off in Settings).
  • It remembers everything - wins, losses, played words, and achievements are saved between sessions.
  • A big-screen mode - the Word Display and full-screen projector views are built for game nights, classrooms, and streams.
Brand new? Do this first Jump to the Quick Start - Your First Game in 5 Steps below. You will have a game running in under a minute.
Showing it to an audience? Open Show Word Window for the live board, or use the new Full-Screen Projector Views - they show the puzzle and standings on a second screen without ever revealing the secret word.

Quick Start - Your First Game in 5 Steps

Set a word

Type a word in Custom Word and press Enter, or click Random Word for a Dutch word from the OpenTaal list.

Add players

Type a name in Add Player and click Add (or press Enter). Repeat for each participant.

Select a player

Click a row in the Players tab. The selected name appears below the player list.

Guess a letter

Type one letter in the large guess box and press Enter or click Process Letter.

Start the timer (optional)

Click Resume Timer to begin the 5-minute countdown. Use Pause Timer to stop the clock during discussions.

Setting the Word

Custom Word

Enter any word in the Custom Word text field (top-right) and press Enter. The word is converted to uppercase automatically. Spaces and special characters are supported.

Random Word

Click Random Word. Galgje picks a word from the OpenTaal Dutch word list. The button shows "Loading..." while fetching. A bundled offline list is included with the installer; updates are cached in your AppData folder.

Reuse a Played Word

Go to the Played words tab, find a word (use the search box to filter), and double-click it to set it as the current word instantly.

New Game

Click New Game to reset the board, clear guessed letters, reset the hangman, and automatically fetch a new random word. Player stats from the previous round are saved first.

TipWhen switching words mid-game, the timer remembers whether it was paused - it does not auto-start on a new word.

Managing Players

Adding Players

  1. Click the Players tab (right panel, bottom).
  2. Type a name in the Add Player field.
  3. Click Add or press Enter.

Each new player starts with 0 wrong guesses and 0 total guesses. Default players can be pre-loaded from a default_players.ini file if present.

Selecting a Player

Click any row in the Players grid. The Selected Player label updates immediately, and the letter guess box receives focus so you can type right away. Eliminated players have their guess box disabled.

Players Grid Columns

Removing a Player

Select the player, then click Remove Player. Their all-time statistics are preserved even after removal.

Setting Errors Manually

Select a player, enter a number in the errors spinner, and click Set. Useful for correcting mistakes or applying house rules.

Reset Individual Stats

Select a player and click Reset Player's Stats to zero their all-time statistics. This cannot be undone without a backup.

Guessing Letters

  1. Select an active player from the Players grid.
  2. Type one letter in the large "Guessed Letter" box (only A–Z).
  3. Press Enter or click Process Letter.

What Happens Next

✅ Correct Guess

All instances of the letter are revealed in the word display. Timer gains +20 seconds. Game summary copied to clipboard.

❌ Wrong Guess

Letter added to wrong letters list. Hangman advances one stage. Timer loses −30 seconds. Wrong-guess sound plays (unless muted).

🔁 Duplicate Guess

Guessing a letter already tried counts as a wrong guess - even if another player guessed it first.

ImportantOnly one letter per guess. The input box accepts a single character and auto-uppercases it.

Elimination & Winning

Automatic Elimination

Players are automatically eliminated when they reach their wrong-guess limit (see Game Rules).

Manual Elimination

Select a player and click Eliminate Player. They can no longer guess but remain visible in the player list.

Un-Eliminate

Click Un-Eliminate (in the Players tab area) to restore an eliminated player back to active status.

Mark as Winner

Click Mark as Winner to declare the selected player the winner. This triggers:

  • Victory "BING BING" sound (unless muted)
  • Winner overlay on the Word Display window
  • Automatic screenshot copied to clipboard
  • Statistics and achievement updates

Word Completion

When all letters are guessed correctly, the game ends automatically. All active players receive appropriate stat updates.

Timer System

Each game has a 5-minute (300 second) countdown. The timer does not start automatically - you control it manually.

  • Orange - 3:30 to 1:00 remaining
  • Red - Less than 1:00 remaining
TipPause the timer during word discussions or rule explanations. The paused state is preserved when you switch words.

Host / AzzMastah Rule

The Hoster-name field (default: AzzMastah) identifies the game host. Add "AzzMastah" (or your custom host name) as a regular player for the special host win rules to apply.

When the Host Wins Automatically

  • 10 total wrong guesses are reached across all players
  • The timer expires (reaches 0:00)

In both cases, the host is declared winner, a special overlay is shown, and the Word Display screenshot is copied to clipboard. The "The Chosen One" achievement unlocks for this feat.

Customize the host nameClick the Hoster-name field, clear "AzzMastah", and type your preferred host name. It appears on winner screens.

Word Display Window (Secondary Presentation Window)

The Word Display Window is a dedicated secondary window ideal for projectors, large screens, and streaming scenarios.

What the Word Display Shows

  • Current Word - Large display with revealed and hidden letters
  • Player Cards - Each player's name, status, and progress
  • Hangman Drawing - Live visual representation of wrong guesses
  • Correct/Wrong Letters - Organized lists of guessed letters
  • Timer - Large countdown display
  • Winner Overlay - Automatic announcement when game ends

How to Use

  1. Click Show Word Window from the main window (or enable Open on startup in Settings → Display)
  2. Move it to your projector or second monitor - position is remembered if enabled in Settings
  3. Adjust font size in Settings → Display (Small / Medium / Large) if needed for the room
  4. Play normally on the main window - Word Display updates in real-time
  5. On game over or winner, the window automatically captures and copies to clipboard
Streaming tip Keep the Word Display on your stream monitor while operating the main window on your control screen.

Network Multiplayer (LAN)

Play Hangman together over your local network: one player hosts with the full control window; others join from their own PC and guess remotely. Open Network Game in the menu bar (between Players and View).

Hosting a Game

  1. Open Network Game → Host Game. The server starts on port 8080.
  2. A modeless status window shows your IP address and port (e.g. 192.168.1.100:8080), connected players, and Copy Address. Share that address with other players.
  3. On first host, Galgje may offer to add a Windows Firewall rule for port 8080 (you can also dismiss with “Do not show again”).
  4. Keep playing in the main window as usual - closing the status window does not stop hosting. Use Network Game → Disconnect or Stop Hosting to end the session.
  5. The network status indicator above the status bar shows Hosting with the number of connected clients.
  6. Open Network Game → Connection Stats for live traffic, latency, sync packets, and uptime (can be minimized; not always-on-top).

Joining a Game

  1. Open Network Game → Join Game, enter the host's IP address, port, and your player name.
  2. A connecting progress window appears while Galgje connects and synchronizes game state.
  3. After connecting, the app switches to client mode: you see the Current Word Progress window and Live Stats. The secret word stays hidden until the round ends.
  4. You are automatically added to the host's player roster under your chosen name.

Connection Stats

Available for host and clients while connected. Useful to confirm traffic is flowing and to diagnose lag or firewall issues.

Guessing as a Joined Player

  • Letter guess - type a letter in the Your guess box and press Enter (or click Send Guess).
  • Whole word guess - type the complete word in the Guess word box. Correct = instant win for you; wrong = elimination (same as a wrong letter limit).
  • A 5-second cooldown between guesses is shown in the UI so everyone can follow the pace.
  • Guess input locks when you are eliminated, the round is over, or the host has not set a word yet (the reason is shown).

End of a Round - the BING BING Recap

When the word is completed, guessed outright, the hangman is complete, or the host marks a winner, everyone - host and all clients - hears the BING BING sound and sees the same Round Finished! window with the revealed word, winner, full guess timeline, per-player results, and eliminations. The host automatically gets the recap image on the clipboard; every player can copy it with one click.

Version compatibility

Host and joining players must run Galgje builds within 15 releases of each other. Each build carries a signed list of the last 15 official release timestamps (compiled into the app, not an editable file). If versions are too far apart, join is blocked with a link to GitHub Releases to download a matching build.

Good to know Your offline game is saved when you host or join, and restored automatically when the network session ends - network rounds do not write to clients' local statistics history.
Firewall If players cannot connect, allow GalgjeApp (or TCP port 8080) through Windows Firewall on the host. Use the built-in port check when hosting, or add the rule from the prompt.

The live player roster with real-time statistics. Click any row to select that player for guessing. Columns update instantly after each letter processed.

History of all words used in previous games. Use the Search Played Word box above the tabs to filter the list. Double-click a word to reuse it. Select a word and click Delete (if available) to remove it from history.

Timestamped record of every game event: word selections, guesses, eliminations, wins, and system messages. Use Copy Last 25 Log Lines to share recent activity. Clear Log empties the log (saved to file immediately).

Free-form text area for house rules, word hints, session notes, or observations. Notes auto-save as you type - no save button needed. Content persists between sessions.

Audience-safe by design None of these views ever reveal the secret word. The Word Progress view shows only the letters that have already been guessed (everything else stays masked as _), and the stats views show standings and numbers - never the current answer.

Backup & Restore

Galgje offers several backup paths: stats-set backups (one league/season), full AppData ZIP backups (all sets + settings), and restore from ZIP files on disk or USB. Everything is available from multiple places so you do not have to hunt through menus.

The Action Selector Dialog

Access: Backup/Restore/Reset Stats (bottom of main window) · Tools → Backup and Reset All Stats · Settings → Data & Privacy · Player Manager → Tools · Stats Control Center · Data Manager

Option 1: Create Backup Set

Copies the active stats-set into a new backup set named Backup of …-yyyyMMdd_HHmmss. You can optionally reset the active set afterward.

Backed up: player statistics, game log, achievements, notes, played words, and related set files.

Option 2: Backup All Data to ZIP

Creates Galgje-DataBackup-yyyyMMdd_HHmmss.zip in %LocalAppData%\Galgje\backups\ containing all sets, settings, and global files (the backups folder itself is excluded to avoid nesting).

Use this before major upgrades, PC migration, or as a complete safety snapshot.

Option 3: Restore from ZIP

Pick any .zip file. Galgje detects the type automatically:

  • Stats-set ZIP - overwrites only the active stats-set files.
  • Full data ZIP (Galgje-DataBackup-*.zip) - restores all AppData data (sets, settings, registry). Requires confirmation; reloads settings and stats-set list afterward.

Option 4: Restore from Backup Browser

  1. Click Restore from Backup in the action dialog, or Tools → Restore Backup.
  2. Select a row (source type shows Local, Folder, ZIP, or Full data ZIP).
  3. Restore to Active - overwrites the active set (or full AppData for full-data ZIP).
  4. Restore to New Set - available for local backup sets only; creates a new named set.
  5. Browse folder… / Browse ZIP… - restore from USB or network share.
  6. Backup all data to ZIP… / Restore from ZIP… - quick actions in the same dialog.

Option 5: Reset Stats (No Backup)

Clears all stats in the active set without creating a backup first. Strong confirmation required. Clears stats, log, achievements, and notes (played words are kept).

Where Else to Find Backup Tools

  • Player Manager → Tools - Backup ZIP, Restore ZIP, full-data ZIP backup
  • Data Manager - per-set backup/restore, full-data ZIP, restore from ZIP
  • Settings → Data & Privacy - scheduled auto-backup, open backup folder (…\Galgje\backups)
Pro tip Create a full-data ZIP at the end of each season and a set backup before risky experiments. Restoration from ZIP is the fastest way to recover on a new PC.
Full-data restore overwrites AppData Files in the ZIP replace matching paths under %LocalAppData%\Galgje. Confirm you selected the correct archive.

Copy & Export Options (Tools Menu)

Galgje provides powerful copy and export features to share game data, statistics, and reports. All copy operations automatically place content in your clipboard for immediate pasting into documents, emails, or other applications.

📋 Copy Word Progress

What it does: Copies the current game state to your clipboard (word display, correct letters, wrong letters, active players, timer remaining).

Use case: Share the current game board with remote players, screenshots, or documentation.

Output format: Plain text, formatted for readability:

_ _ _ _ _ _ _

Total wrong guesses: 2

Correct letters: A, E, O
Wrong letters: X, Z
Active players: 3
Time remaining: 04:32

Use case: Create a leaderboard for email, documents, or share current standings.

Dialogs & Settings Reference

Galgje includes several dialogs and settings windows to customize your game experience. Here's a complete guide:

Settings Dialog

Access: Tools → Settings (Ctrl+,) or Main menu button

Tabs:

  • General - UI language, word list language, hoster name, confirmations, logging options, active stats set, reset/import/export settings, link to Game Rules
  • Tonight - roster source for new games, auto-load roster, open Player Manager Home on startup, shortcuts to Roster and Home
  • Timer - default duration, correct/wrong bonus/penalty, auto-start; quick presets (3 / 5 / 10 / 15 min)
  • Display - word window on startup, always on top, remember Player Manager tab, font size preset, remember window position/monitor
  • Export & PDF - export folder, log lines, HTML/PDF behavior, shortcuts to export tools
  • Data & Privacy - backup on exit, metrics, automatic scheduled backup, Backup all data to ZIP, Restore from ZIP, open backup folder (…\Galgje\backups), link to Backup & Restore
  • Sound - mute, volume slider, achievement popup toggle, auto-copy achievement image
  • Keyboard shortcuts - customize shortcuts for every menu command

Game Rules Dialog

Access: Tools → Game Rules (Ctrl+G)

Tabs: Global (limits, elimination, winner mode, repeat behavior, word-length scaling), Per player, Per word, Teams, and Current game (live status while a round is active).

Presets: Classic, Relaxed, Speed, Kids - plus Reset overrides, Import/Export rules file, Copy rules summary, and a link to Settings.

About Dialog

Access: Help → About

Shows: Current version, .NET runtime version, and application information

Player Manager Dialog

Access: Players → Player Manager (Ctrl+Shift+P) · jump tabs via the Go to dropdown in the header · Ctrl+K Command Palette from the main window

Global search (under the header) finds players, words, and games across the manager.

Tabs: Home (tonight dashboard), Game Hub (filter and export finished games), Players, Leaderboard, Hall of Fame, Compare, Export, Explore, Teams, Word History, Game Editor, Insights, Achievements, Roster, Active Game, and Tools. Hover any tab header for a short tooltip.

Game Hub: browse finished games with filters (player, word, dates, winner, outcome, length, and more). Use presets (Tonight, 7 days, 30 days, All) or save your own. Sort columns, copy a snapshot to the clipboard, or bulk-export HTML/CSV. Shift+double-click a row to compare players from that game. Also reachable via Players → Game Hub or Tools → Game Hub.

Game Editor: select a finished game to fix the word, winner, start/end times, participating players, and individual guesses. Use Save to write changes to history; optionally recalculate player statistics afterward. Quick actions include duplicate, delete, sync players from guesses, and set winner from the last correct guess.

Tools → Reset all: permanently wipes all stats, custom stats sets (keeps Default), achievements, profiles, and word history. A detailed confirmation dialog is shown first.

Tools → Backup & restore: same five-option backup wizard as the main window (set backup, full-data ZIP, restore from ZIP, browse backups, reset).

Features:

  • View all players and their statistics
  • Leaderboard - sortable standings, charts, activity graph, and a compact Hall of Fame sidebar with rank badges (Gold / Silver / Bronze for the top 3)
  • Hall of Fame - dedicated tab with career highlights (champion, sharpshooter, hot streak, rivalries, and more) in a two-column badge layout
  • Head-to-head and multi-player comparisons with export options
  • View player achievements and badges
  • Reset individual player stats or delete players

Stats Editor Dialog

Access: Edit → Edit Data Files → Player Statistics (or from Player Manager)

Features:

  • View and edit all player statistics in a sortable spreadsheet-style grid
  • Filter by player name; click a row for a rich detail panel (career, guessing stats, league standing)
  • Delete players via button, context menu, or Delete key
  • Columns include wins, losses, win %, average errors, and accuracy %
  • Save changes to the selected stats set (not always the active set)

Stats Export Dialog

Access: Edit → Statistics Export Center or Tools → Copy & Export

Formats:

  • HTML (for printing or web viewing)
  • CSV (for spreadsheets)
  • Text (plain format for sharing)
  • Image (screenshot format for social media)

Stats Sets Manager Dialog

Access: Tools → Stats Sets → Manage Stats Sets

Features:

  • Create new statistics sets (e.g., "Tournament 1", "League Season 2")
  • Switch between sets instantly
  • Rename and delete sets
  • Copy players between sets
  • Move players with all their stats

Data Manager Dialog

Access: Edit → Data Manager (or Tools → Data Manager)

Manage:

Analytics Dashboard

Access: Tools → Analytics Dashboard

Metrics displayed:
