1. Getting started

  • Install from the latest GalgjeSetup-v20.1.3.20260714180843.exe on GitHub Releases, or run from source with BuildAndRun.bat.
  • On first launch, sample players may be created if you have no statistics yet.
  • By default, game data is stored in %LocalAppData%\Galgje and survives upgrades.
  • You can point game data to another folder — including a network share — via Settings → Data locations (see section 6).

2. Playing a game

  1. Choose New Game and pick English or Dutch words.
  2. Click letters or type them to guess the hidden word.
  3. You have a limited number of wrong guesses before the round ends.
  4. Winners and statistics are recorded automatically after each round.

A subtle game elapsed time counter appears at the bottom-right of the main window (above the copyright line). The same elapsed time is shown on the Live Stats board, Word Progress window, and in winner/dashboard screenshots. Time includes resumed games.

3. Player Manager

Open via Players menu or toolbar. Key tabs:

All Players / LeaderboardBrowse and compare career statistics

Stats AuditPermanent log of every stat change (who, when, old/new values)
Stats HealthFind inconsistencies; ignore known differences

Stats Audit

The Stats Audit tab records every change to player statistics in a permanent log file (stats_audit.jsonl) per stats set. Use the filter bar to narrow by player, change source (manual edit, game end, import, reconcile), and date range.

  • Manual edits in the stats editor are logged before saving.
  • Game-end stat updates are logged automatically.
  • Imports and reconcile operations are tagged with their source.
Statistics are authoritative. When you manually edit a player's stats and save, those numbers stay as you set them. The game does not silently overwrite your edits.

4. Word Browser

Available under Tools → Word Browser and as a tab in Player Manager.

  • Filter by language, length, contains/starts/ends, pattern (_ = wildcard).
  • Filter by Played words only to review words you have already used in games.
  • Enable Look up meanings online to show definitions in the analysis panel.
  • Sources: Wiktionary, Van Dale (Dutch), or OpenTaal.
  • Use Use Word to set the selected word for the next game.

5. Network play

Host or join games over the local network. Versions must be within the supported release range (based on internal release numbers, not the visible timestamp).

6. Data, backups & locations

Default storage

  • Game data (stats, logs, word history, stats sets, backups): %LocalAppData%\Galgje
  • App settings (language, shortcuts, window positions): same folder, file game_settings.ini — always kept on this PC
  • Daily automatic ZIP backups (last 7 days kept)
  • Installer options: keep, back up, or delete existing data on upgrade
  • Data Manager: edit stats, logs, played words, backups

Custom & network data locations

Open Settings → Data locations to manage where game data is stored:

  • Overview — shows settings folder, current game data folder, and active stats set path.
  • Custom folder — point Galgje to a local folder or network share (e.g. \\server\share\Galgje or G:\GalgjeData).
  • Test access — verifies read/write permissions before switching.
  • Copy or move — migrate existing data to the new folder; optional ZIP backup first.
  • Network warning — optional startup alert if the configured network folder is unavailable.
Restart required. After changing the game data location, restart Galgje so all windows use the new folder. App settings always remain on this PC.
Network shares. Use one PC at a time when writing to a shared folder to avoid file conflicts.

8. Troubleshooting

ProblemSolution
Stats look wrong after manual editYour saved edit is correct; use Stats Reconcile only if you want to compare with history
Stats Audit list is emptyAudit logging starts from v20.1.3; older changes are not backfilled. Make a test edit to verify logging works.
Network data folder unavailable at startupCheck your connection or open Settings → Data locations to change the folder or disable the startup warning
Changed data location but old data still shownRestart Galgje after changing the folder in Settings
Word meaning not foundTry another source (Van Dale for Dutch); links may still appear in the meaning box
Network version mismatchInstall the same or compatible release on all machines
Dialog text or buttons overlapUpdate to the latest version; v20.1.3 includes layout fixes across Settings, Player Manager, and related dialogs
