Galgje — User Manual

Version v20.1.1 · July 14, 2026 · Copyright © 2026 Thijs Boekholt

Galgje is a feature-rich Hangman word game for Windows with statistics, achievements, multiplayer, and extensive player management tools.

1. Getting started

  • Install from the latest GalgjeSetup-v20.1.1.*.exe on GitHub Releases, or run from source with BuildAndRun.bat.
  • On first launch, sample players may be created if you have no statistics yet.
  • Your data is stored in %LocalAppData%\Galgje and survives upgrades.

2. Playing a game

  1. Choose New Game and pick English or Dutch words.
  2. Click letters or type them to guess the hidden word.
  3. You have a limited number of wrong guesses before the round ends.
  4. Winners and statistics are recorded automatically after each round.

3. Player Manager

Open via Players menu or toolbar. Key tabs:

TabPurpose
All Players / LeaderboardBrowse and compare career statistics
Hall of FameAchievement badges with prominent player names
Word BrowserSearch Dutch/English dictionaries, filter words, look up meanings
Stats ReconcileCompare saved stats with history-rebuilt stats
Stats AuditPermanent log of every stat change (who, when, old/new values)
Stats HealthFind inconsistencies; ignore known differences
Statistics are authoritative. When you manually edit a player's stats and save, those numbers stay as you set them. The game does not silently overwrite your edits.

4. Word Browser

Available under Tools → Word Browser and as a tab in Player Manager.

  • Filter by language, length, contains/starts/ends, pattern (_ = wildcard).
  • Filter by Played words only to review words you have already used in games
  • Enable Look up meanings online to show definitions in the analysis panel.
  • Sources: Wiktionary, Van Dale (Dutch), or OpenTaal.
  • Use Use Word to set the selected word for the next game.

5. Network play

Host or join games over the local network. Versions must be within the supported release range (based on internal release numbers, not the visible timestamp).

6. Data & backups

  • Game data: %LocalAppData%\Galgje
  • Daily automatic ZIP backups (last 7 days kept)
  • Installer options: keep, back up, or delete existing data on upgrade
  • Data Manager: edit stats, logs, played words, backups
